# 代码审查修复记录

本文件记录 v0.2 稳定性修复内容。

## 已修复

1. 日志与错误可观测性
   - 新增 `app/utils.py` 的 `setup_logging`。
   - 主流程写入 `data/logs/daily.log`。
   - 扫描失败会记录股票代码、名称和异常类型。
   - 报告中展示扫描数量、跳过数量、候选数量、过滤原因和错误统计。

2. 数据清洗
   - 新增 `safe_float`、`safe_int`、`normalize_code`。
   - AkShare 数据源统一清洗 `-`、空值、百分号、逗号数字。
   - 财务字段 PE/PB 不再直接 `float()`。

3. 股票过滤
   - 新增 `app/strategies/risk_filters.py`。
   - 过滤 ST、退市、北交所/旧市场代码、停牌/无效价格、低成交额、涨跌停附近股票、历史不足股票。

4. 股票池排序与扫描范围
   - 股票列表按成交额降序排序，避免只扫描接口默认前 500 只。
   - 默认扫描 1500 只，可通过 `MAX_STOCKS_TO_SCAN=ALL` 扫描过滤后的全部股票。
   - 默认最低成交额 `MIN_AMOUNT=100000000`。

5. 数据缓存
   - 日线数据缓存到 `data/cache/daily/{code}.csv`。
   - 默认缓存有效期 18 小时，减少每天全量重复请求。

6. AI 输出校验
   - AI 返回必须是 JSON 数组。
   - 支持从 Markdown 代码块中提取 JSON。
   - AI 推荐的股票必须来自候选列表，禁止编造股票。
   - 必填字段缺失时回退到本地规则评分。

7. 数据库评分
   - 保存推荐时优先使用 `ai_score`，没有时才使用 `score`。

8. Web 安全与任务控制
   - `/run` 从 GET 改为 POST。
   - 新增后台任务锁，防止重复运行。
   - 新增 `/status` 查看任务状态。
   - HTML 输出统一转义，降低本地页面注入风险。

9. 定时任务
   - 使用 `TIMEZONE` 和 `DAILY_RUN_TIME` 配置。
   - 调度循环按配置时区判断，不依赖主机本地时区。

10. 依赖与测试
   - `requirements.txt` 改为版本范围。
   - 新增 pytest。
   - 新增基础测试：工具函数、策略触发、AI fallback。

## 仍需人工验证

- AkShare 个股新闻接口在本地环境中的可用性。
- 不同交易日、节假日、接口限流情况下的稳定性。
- 策略参数是否符合你的实际交易风格。
- AI Key 配置后的真实输出质量。
