# A股本地股票买卖方案推荐平台

这是一个**本地运行**的 A 股股票买卖方案推荐平台。它会在每天晚上 20:00 自动更新数据，执行多套选股策略，再调用 AI 对候选股票进行综合分析，最终输出近期最推荐的 3 只股票及对应交易计划。

> 重要声明：本项目仅用于学习、研究和辅助决策，不构成投资建议。A 股市场风险高，任何策略都可能失效，请自行承担交易风险。

## 核心目标

平台每天完成以下流程：

1. 自动更新 A 股行情、指数、资金流、基础财务和市场消息。
2. 运行多套适合 A 股的选股策略。
3. 为每只候选股生成买入时机、止损位、止盈位、仓位建议和持仓周期。
4. 调用 AI 综合分析：市场消息、盈利空间、回撤风险、资金热度、策略共振程度。
5. 输出当天或近期最推荐的 3 只股票交易方案。

## 当前内置策略

### 1. 趋势龙头策略

适合 A 股主线行情，比如 AI、半导体、机器人、高端制造等。

核心条件：

- 股价在 20 日均线和 60 日均线上方。
- 20 日均线高于 60 日均线。
- 近 20 日涨幅强于市场指数。
- 成交额放大，资金活跃。
- 优先选择板块内强势股。

交易计划：

- 买入时机：回踩 20 日线不破，或放量突破近期平台。
- 止损：跌破 20 日线或买入价下方 6%~8%。
- 止盈：达到 15%~25% 后分批止盈，或跌破 10 日线减仓。
- 持仓周期：5~20 个交易日。

### 2. 放量突破策略

适合指数放量、市场情绪上升时。

核心条件：

- 突破近 60 日高点。
- 当日成交量大于 20 日均量的 1.5 倍。
- 收盘价靠近当日高位。
- 避免连续一字涨停、极端高位股。

交易计划：

- 买入时机：突破后次日不低开破位，或盘中回踩突破位企稳。
- 止损：跌回突破位下方 3%~5%。
- 止盈：第一目标 10%~15%，强势股用移动止盈。
- 持仓周期：3~10 个交易日。

### 3. 低波动质量趋势策略

适合震荡市和中线配置。

核心条件：

- 股价稳定站上 60 日均线。
- 近 20 日波动率低于市场平均。
- ROE、毛利率、现金流等质量指标较好。
- 回撤小、趋势稳定。

交易计划：

- 买入时机：回踩 60 日线或 20 日线企稳。
- 止损：跌破 60 日线或基本面显著恶化。
- 止盈：20% 以上分批兑现，趋势未破可继续持有。
- 持仓周期：20~60 个交易日。

### 4. 超跌反弹策略

适合市场急跌后的修复行情，不适合熊市单边下跌。

核心条件：

- RSI 低于 30 后重新上穿。
- 股价偏离 20 日均线过大后回归。
- 成交量出现修复。
- 优先选择基本面没有明显雷点的股票。

交易计划：

- 买入时机：止跌阳线确认，或 RSI 上穿 30。
- 止损：跌破近期低点。
- 止盈：反弹至 20 日线附近先减仓。
- 持仓周期：2~8 个交易日。

### 5. 大盘择时与仓位控制

所有策略都会受到市场环境约束。

市场状态：

- 强势市场：指数在 20 日和 60 日均线上方，成交额放大。
- 震荡市场：指数在 20 日线附近反复。
- 弱势市场：指数低于 60 日线，成交额萎缩。

仓位建议：

- 强势市场：单票 20%~30%，总仓位 60%~80%。
- 震荡市场：单票 10%~20%，总仓位 30%~50%。
- 弱势市场：单票不超过 10%，总仓位 0%~30%。

## 数据来源与更新方式

默认使用公开数据源，适合本地个人研究。

| 数据 | 默认来源 | 获取方式 |
|---|---|---|
| A 股实时/日线行情 | AkShare 东方财富接口 | `ak.stock_zh_a_spot_em` / `ak.stock_zh_a_hist` |
| 指数行情 | AkShare | `ak.stock_zh_index_daily_em` |
| 资金流 | AkShare 东方财富接口 | `ak.stock_individual_fund_flow` |
| 财务指标 | AkShare / Tushare 可选 | 公开接口或 Tushare Token |
| 市场新闻 | AkShare 财经新闻接口 / 东方财富 RSS 备选 | 本地抓取后缓存 |
| AI 分析 | OpenAI-compatible API | 本地 `.env` 配置 API Key |

数据更新计划：

- 每天 20:00：更新行情、指标、资金流和新闻。
- 更新后自动运行策略。
- 生成 `data/reports/latest_report.md`。
- 同时写入 SQLite 数据库。

## 本地运行

### 1. 克隆项目

```bash
git clone https://github.com/txq85721-wq/A.git
cd A
```

### 2. 创建虚拟环境

```bash
python -m venv .venv
source .venv/bin/activate  # Windows 使用 .venv\\Scripts\\activate
```

### 3. 安装依赖

```bash
pip install -r requirements.txt
```

### 4. 配置环境变量

```bash
cp .env.example .env
```

填入你的 AI Key。如果没有 AI Key，平台仍会输出规则策略结果，但 AI 综合分析会使用本地规则摘要代替。

### 5. 手动运行一次

```bash
python run.py --once
```

### 6. 启动本地 Web 平台

```bash
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

打开：

```text
http://127.0.0.1:8000
```

### 7. 启动定时任务

```bash
python run.py --schedule
```

服务会在每天晚上 20:00 自动更新数据并生成推荐报告。

## 输出结果

推荐报告会包含：

- 推荐股票代码和名称。
- 推荐策略来源。
- 买入时机。
- 止损位。
- 止盈位。
- 建议仓位。
- 持仓周期。
- 推荐理由。
- 最近市场消息。
- 盈利空间和回撤风险评估。
